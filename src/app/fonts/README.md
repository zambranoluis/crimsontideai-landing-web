# Roboto web fonts

This directory bundles the complete standard Roboto variable family used by the site:

- `Roboto[wdth,wght].ttf` — upright, weight 100–900
- `Roboto-Italic[wdth,wght].ttf` — italic, weight 100–900

Both files include the font's published Cyrillic, Cyrillic Extended, Greek, Greek Extended, Latin, Latin Extended, Vietnamese, Math, Symbols, and Menu coverage. The width axis spans 75–100; the site uses the standard normal width.

Source: [Google Fonts Roboto directory](https://github.com/google/fonts/tree/809e4d8b8d7e9364a914909bb777679606c178b8/ofl/roboto), pinned to commit `809e4d8b8d7e9364a914909bb777679606c178b8`. Upstream source metadata and coverage are preserved in `METADATA.pb`; the original license is preserved in `OFL.txt`.
